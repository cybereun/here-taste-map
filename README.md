# 🗺️ 여기 어때 맛지도 (Here TasteMap)

> 래비(`cybereunny`)의 네이버 블로그에 포스팅된 카페·맛집을 한눈에 보고 길찾기까지 지원하는 모바일 맞춤형 맛지도 앱 (PWA)

---

## ✨ 주요 기능

1. **블로그 기반 100% 실기록 맛지도**:
   - 블로그 카테고리 22에 등록된 **320+개**의 실제 방문 카페·맛집을 지도에 시각화
   - ☕ 카페, 🥐 베이커리, 🍝 양식, 🍣 일식, 🥩 한식/고기 등 업종별 귀여운 핀 마커
2. **원클릭 네이버 지도 길찾기 연동**:
   - 모바일 기기에서는 네이버 지도 앱으로 바로 연결 (`nmap://`)
   - PC 또는 미설치 기기에서는 네이버 지도 웹 길찾기로 즉시 연결
3. **내 위치 기반 가까운 순 정렬**:
   - 상단 [내 위치] 버튼을 누르면 GPS로 현재 위치를 파악하여 가장 가까운 맛집부터 거리(m/km) 순으로 정렬
4. **도시/지역 및 음식 종류 필터**:
   - 대구 수성구, 서울 강남구, 용산구 등 지역별 원클릭 필터링
   - 음식 및 카페 종류별 빠른 분류
5. **모바일 PWA 앱 지원**:
   - 스마트폰 브라우저에서 '홈 화면에 추가'를 누르면 네이티브 앱처럼 아이콘과 함께 독립 실행
   - 브라우저 탭 파비콘 및 고해상도 앱 아이콘 완비
6. **매시간 자동 수집 & 갱신**:
   - GitHub Actions가 매시간 17분에 카테고리 22의 공개 글을 수집합니다. 실행 대기와 배포 시간만큼 반영이 늦어질 수 있습니다.
   - 블로그 글에 네이버 장소 태그가 있으면 좌표를 추출해 지도에 반영합니다. 전화번호가 없어도 수집하며, 좌표를 찾지 못한 글은 다음 실행에서 다시 확인합니다.
   - 수집 오류 시 기존 데이터를 보존하고 자동 실행을 실패 처리합니다.
   - 앱을 다시 활성화하거나 열어 둔 상태에서 5분마다 최신 데이터를 확인합니다. 갱신 실패 시 이미 표시된 장소는 유지합니다.

## 🚀 로컬 실행 방법

### 1. 개발 서버 실행
```bash
cd l:\codex-L\here-taste-map
npm run dev
```
브라우저에서 `http://localhost:3000` 접속

### 2. 신규 블로그 글 업데이트 (크롤러 실행)
```bash
# Windows
run_daily_update.bat

# 또는 Python 직접 실행
python scripts/crawler.py
```

## 📱 스마트폰에서 앱으로 설치하는 방법 (PWA)

1. 스마트폰 모바일 브라우저(사파리 또는 크롬)로 웹사이트 접속
2. **iPhone (Safari)**: 하단 공유 버튼 클릭 → `[홈 화면에 추가]` 선택
3. **Android (Chrome)**: 우측 상단 메뉴(⋮) 클릭 → `[앱 설치]` 또는 `[홈 화면에 추가]` 선택
